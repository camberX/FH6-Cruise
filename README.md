# FH6-Cruise
Semi-Advanced Cruise Control for Forza Horizon 6, has an ingame overlay, adjustable speed keybinds (with Controller support), idk its Cruise Control, pretty self explanatory

How to use:

1. Download a Release (or build it yourself)
2. Run the .exe
3. Enable Telemtry ingame, set the IP to 127.0.0.1 and the Port to 20055 (This is used to track your current speed)
4. Change keybinds, move the overlay, change the catch-up time
5. Go ingame and press the "Cruise" keybind while going a speed u want it to keep. It will now hold that speed automatically. Use the Increase and Decrease keybinds to change the selected speed on the fly (5 kmh/mph intervals)
